# Лабораторная работа №7. Работа с базой данных (SQLite) и CRUD-операции

Данный проект представляет собой REST-подобный API для управления статьями блога (поддержка черновиков и публикаций). Разработан в рамках выполнения лабораторной работы (Вариант 9).

## Цель работы
Изучить основы работы с реляционными базами данных, реализовать классические CRUD-операции и интегрировать их с маршрутами веб-сервера Express.

## Вариант 9: Тема «Статьи блога»

### Сущность `articles` (Таблица в БД)
* `id` — INTEGER, первичный ключ с автоинкрементом.
* `title` — TEXT, заголовок статьи (обязательное поле).
* `content` — TEXT, текст статьи.
* `is_published` — BOOLEAN, статус публикации (0 — черновик, 1 — опубликовано). По умолчанию: 0.
* `published_at` — TEXT, дата и время публикации.

### Реализованная бизнес-логика
1. **Модульность:** Работа с базой данных вынесена в отдельные изолированные файлы (`database.js` и `db_crud.js`).
2. **Фильтрация:** Эндпоинт получения статей поддерживает query-параметр `?published=true`, возвращающий строго опубликованные материалы.
3. **Сортировка:** Добавлена сортировка по дате публикации (`published_at DESC`) — новые статьи выводятся вверху списка.
4. **Валидация:** При попытке создать статью без указания `title` сервер возвращает ошибку со статусом `400 Bad Request`.
5. **Автоматизация:** При публикации статьи (`PUT`-запрос) сервер автоматически выставляет текущую дату и время (`datetime('now')`).

## Спецификация API (Маршруты)

| Метод | Маршрут | Описание | Параметры / Тело запроса | Ожидаемый статус |
| :--- | :--- | :--- | :--- | :--- |
| **GET** | `/api/articles` | Получить все статьи (черновики + публикации) | Нет | `200 OK` |
| **GET** | `/api/articles?published=true` | Получить только опубликованные статьи | Query-параметр `published=true` | `200 OK` |
| **POST** | `/api/articles` | Создать новую статью (как черновик) | JSON: `{"title": "...", "content": "..."}` | `201 Created` |
| **PUT** | `/api/articles/:id` | Опубликовать статью по её ID | Параметр пути `:id` | `200 OK` |
| **DELETE** | `/api/articles/:id` | Удалить статью по её ID | Параметр пути `:id` | `200 OK` |

## Примеры тестирования запросов (cURL)

**1. Тест валидации (отправка без `title`):**
```bash
curl -X POST http://localhost:3000/api/articles -H "Content-Type: application/json" -d "{\"content\": \"Текст без заголовка\"}"
```
*Ответ:* `400 Bad Request` -> `{"error":"Поле 'title' обязательно для заполнения"}`

**2. Создание корректного черновика:**
```bash
curl -X POST http://localhost:3000/api/articles -H "Content-Type: application/json" -d "{\"title\": \"Новая статья\", \"content\": \"Текст статьи\"}"
```
*Ответ:* `201 Created` -> `{"status":"success","message":"Статья успешно создана как черновик","articleId":1}`

**3. Получение списка всех статей:**
```bash
curl http://localhost:3000/api/articles
```
*Ответ:* `200 OK` -> `{"status":"success","data":[{"id":1,"title":"Новая статья","content":"Текст статьи","is_published":0,"published_at":null}]}`

**4. Публикация созданной статьи:**
```bash
curl -X PUT http://localhost:3000/api/articles/1
```
*Ответ:* `200 OK` -> `{"status":"success","message":"Статья с ID 1 успешно опубликована"}`

**5. Получение только опубликованных статей:**
```bash
curl "http://localhost:3000/api/articles?published=true"
```
*Ответ:* `200 OK` -> `{"status":"success","data":[{"id":1,"title":"Новая статья","content":"Текст статьи","is_published":1,"published_at":"2026-11-04 11:39:00"}]}`

**6. Удаление статьи:**
```bash
curl -X DELETE http://localhost:3000/api/articles/1
```
*Ответ:* `200 OK` -> `{"status":"success","message":"Статья с ID 1 удалена"}`
